# A bare type covers its LATEST STABLE apiVersion; `type@version` pins one.
# Coverage is deliberately partial: a type@version absent from here reads as
# UNKNOWN at scan time and every schema-derived check disables itself for that
# resource (tools/schema/flags.py). Adding a pin is how an operator extends the
# checks to whatever versions their own templates target.
